# ❋ snowflake.py — 雪花写作法工作台

一个**零依赖**的本地网页工具，用 [雪花写作法（Snowflake Method）](https://www.advancedfictionwriting.com/articles/snowflake-method/) 可视化地设计和管理小说。它把你的设计笔记（Markdown）变成一条可点击的「生长时间线」+ 所见即所得的编辑器——**改网页即改文件**。

适合一边学雪花法一边构思长篇：从一句话概括到场景清单，逐步把零散的点子扩写成完整大纲。

---

## 特性

- 📂 **多文件** —— 顶部下拉切换目录下任意设计文件，一键从模板新建一本。
- 🌱 **生长时间线** —— 雪花各步排成一条时间线，按状态着色，点选即跳到该章节。
- 🚦 **手动三态** —— 每步可在「待办 / 草案 / 完成」间手动切换（存到看板方括号 `[ ]` `[~]` `[x]`）。
- ✏️ **所见即所得** —— 实时预览的 Markdown 编辑器，保存即原子回写原文件。
- 🔄 **自动刷新** —— 外部改了文件，网页约 2.5 秒内自动同步（编辑中不打扰，只提示）。
- 💾 **自动备份** —— 每次保存前写一份 `.bak`，改错了随时回退。
- 🔒 **密码保护** —— 可选密码登录，浏览器弹出登录界面，离开时一键锁屏。
- 📤 **异地备份** —— 支持本地目录备份和 SSH 远程备份，防止整个目录意外丢失。
- 🪶 **零依赖** —— 纯 Python 标准库，拷走就能跑。

## 环境要求

- Python 3.6+（仅用标准库，无需 `pip install`）
- 一个现代浏览器

## 快速开始

最简单：进入你存放设计笔记的目录，直接启动（用默认配置，端口 10000）：

```bash
cd /path/to/your/notes
python3 /path/to/snowflake.py
# 浏览器打开 http://localhost:10000（通常会自动弹出）
```

需要自定义端口、密码或备份时，在笔记目录放一个 `snowflake.json` 配置文件，启动时自动读取：

```bash
cd /path/to/your/notes
python3 /path/to/snowflake.py                            # 自动读取当前目录的 snowflake.json
python3 /path/to/snowflake.py --config /path/to/my.json  # 或显式指定配置文件
```

如果目录里还没有设计文件，点网页右上「＋ 新建」从模板创建第一本。

## 命令行参数与配置文件

工具的命令行参数：

```
python3 snowflake.py [--config 配置文件路径] [-v|--verbose]
```

| 参数 | 说明 |
|------|------|
| `--config` | 配置文件路径。不传则按顺序自动查找：当前目录 `snowflake.json` → 当前目录 `config.json` → 都没有就用内置默认（目录=当前目录，端口 10000，无密码、无备份）。 |
| `-v` / `--verbose` | 打印 HTTP 访问日志（默认静默，仅打印错误与备份告警）。排障时开启。 |
| `-h` / `--help` | 查看帮助。 |

**配置文件字段**（JSON，全部可选，缺什么回退什么默认值）：

| 字段 | 默认 | 说明 |
|------|------|------|
| `dir` | 当前工作目录 | 设计文件（`.md`）所在目录；列出其中所有 `.md`（隐藏文件和 `CLAUDE.md`、`README.md` 除外，大小写不敏感）。 |
| `port` | `10000` | 网页服务端口。 |
| `password` | 无 | 启用密码认证，浏览器显示登录界面；留空或不写则无密码。 |
| `backup_dir` | 无 | 本地异地备份目录，每次保存/新建时自动复制一份。 |
| `backup_remote` | 无 | SSH 远程备份，格式 `user@host:/path/to/backup/`，每次保存时异步 scp 推送。 |
| `backup_password` | 无 | 远程备份的 SSH 密码。填写后用 `sshpass` 自动喂密码（需系统已安装 sshpass）；留空则走免密 key。 |
| `nodes` | 内置 11 步 | 自定义步骤配置数组，每项 `{key, short, full, level, prefix, token}`。 |

示例 `snowflake.json`：

```json
{
  "dir": "/home/me/my-novel",
  "port": 8000,
  "password": "mysecret",
  "backup_dir": "/home/me/backups/snowflake",
  "backup_remote": "user@server:/home/user/novel-backup/",
  "backup_password": "ssh登录密码"
}
```

> ⚠️ **密码安全**：配置文件含明文密码，请务必 ① 把 `snowflake.json` / `config.json` 加入 `.gitignore`（本仓库已默认忽略）；② `chmod 600 snowflake.json` 限制权限；③ 不要放进公开同步盘。

> 工具列出的是 `dir` 下**所有** `.md`。建议给小说笔记单独建个目录，避免和其它 markdown 混在一起。

## 网页用法

- **顶部下拉**：切换 / 新建设计文件（新建会从雪花模板生成骨架）。
- **时间线**：点任一步骤节点，右侧打开该章节。
- **三态开关**：每个雪花步骤可标「待办 / 草案 / 完成」。
- **编辑**：点「编辑」进入 Markdown 编辑器（左写右预览），「保存」回写文件。
- **标题与简介**：左侧栏顶部编辑书名与一句话简介（文件开头 `# 书名` + `> 简介`）。
- **锁屏**：启用密码时，右上角出现 🔒 按钮，点击退回登录界面。

## 密码保护

在配置文件里写 `"password": "mysecret"` 即可启用：

```json
{ "password": "mysecret" }
```

- 打开网页后先显示登录界面，输入密码才能进入。
- 右上角 🔒 按钮一键锁屏，退回登录界面。
- 会话基于 HMAC 签名的 Cookie，24 小时有效。
- 不写 `password`（或留空）则无密码，直接进入主页。

## 备份策略

### 同目录 .bak 备份（默认）

每次保存前，在原文件旁生成 `<文件名>.md.bak`。改错了随时用备份回退。

### 本地异地备份（`backup_dir`）

在配置文件里设置 `"backup_dir": "/home/me/backups/snowflake"`。

每次保存或新建文件时，自动复制一份到指定目录。即使整个工作目录被意外删除，备份目录中仍保留副本。

### SSH 远程备份（`backup_remote`）

在配置文件里设置 `"backup_remote": "user@server:/path/to/backup/"`。每次保存时异步调用 `scp` 推送。支持两种登录方式：

**方式一：免密登录（推荐）**——不填 `backup_password`，依赖已配置的 SSH key（`ssh-copy-id user@server`）。此时 `scp` 以 `BatchMode` 运行，无 key 则快速失败。

**方式二：密码登录**——同时填 `backup_password`，工具调用 `sshpass` 自动喂密码。需要：

1. 系统已安装 `scp`（OpenSSH 客户端）
2. 系统已安装 `sshpass`（如 `apt install sshpass`）；若配了 `backup_password` 但找不到 sshpass，启动时会直接报错退出

> 密码通过环境变量 `SSHPASS` 传给 `sshpass` 子进程，不会出现在 scp 的命令行 / 进程列表里。

备份失败不会阻塞保存操作，控制台会打印警告。

## 设计文件格式

工具靠**约定**识别结构，你的 `.md` 只要有这两块就能用：

**1. 进度看板**（一个二级标题 `## 雪花写作法进度看板`，下面是带方括号的列表）：

```markdown
## 雪花写作法进度看板
- [x] 第0步：核心
- [ ] 第1步：一句话概括
- [~] 第2步：一段话概括
- ...
```

方括号决定状态：`[ ]` 待办 / `[~]` 草案 / `[x]` 完成。匹配按步骤号（`第N步`），**标题后加什么副标题都不影响识别**。

**2. 各步正文**（二级标题 `## 第N步 ...`）：

```markdown
## 第2步 · 一段话概括（定稿）
> 你的五句话三幕概括写在这里……
```

不想手写格式？直接用网页「＋ 新建」，模板会生成完整骨架。

## 雪花写作法步骤

工具内置的完整流程（第0步 + 第1~10步，共 11 步）：

| 步骤 | 内容 |
|------|------|
| 第0步 · 核心 | 统一内核 + 核心矛盾 + 主角 |
| 第1步 · 一句话概括 | 全书一句话 |
| 第2步 · 一段话概括 | 五句话三幕（三次灾难 + 结局） |
| 第3步 · 一页纸人物介绍 | 主要角色各一段 |
| 第4步 · 一页纸大纲 | 把第2步每一句扩成一段 |
| 第5步 · 人物大纲 | 每人一页故事线（含反派） |
| 第6步 · 四页大纲 | 把第4步扩成四页 |
| 第7步 · 人物宝典 | 角色详表 |
| 第8步 · 场景清单 | 全部场景一览表 |
| 第9步 · 场景双模式 | 场景的两页叙述 |
| 第10步 · 写作 | 正文逐章撰写（卡片式逐章编辑） |

## 数据安全

- 所有读写只针对 `dir` 下的 `.md` 文件，且禁止路径越界（`..`、绝对路径、隐藏文件一律拒绝）。
- 每次保存自动生成 `<文件名>.md.bak` 备份。
- `backup_dir` 可将副本存到异地目录，防止整个工作目录丢失。
- `password` 启用密码认证 + CSRF 防护 + 会话签名。
- 配置文件可能含明文密码——已默认在 `.gitignore` 中忽略 `snowflake.json` / `config.json`，仍建议 `chmod 600` 限制权限。
- 工具除 `backup_remote` 的 scp 推送外**不联网**，不上传任何内容。

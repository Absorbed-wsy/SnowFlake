# ❋ SnowFlake V2.0 — 本地小说设计工作台

一个零依赖的本地网页工具，用雪花写作法设计长篇小说，并用可编辑走向图管理主线、人物线、伏笔和关键节点。

## 存储架构

`snowflake.db` 是统一数据源，应用版本为 V2.0，数据库结构版本为 2。数据库分别保存：

- 作品及更新时间；
- 第0～10步的栏目、状态和排序；
- 人物、场景与章节条目；
- 块式富文本文档；
- 走向图栏目、节点、连线和视角；
- 服务端口与访问密码。

正文以结构化 JSON 块保存，段落、标题、列表、表格、引用和重点标注都是独立数据类型。

## 主要功能

- 在一个 SQLite 数据库中管理多部作品；
- 雪花写作法第0～10步及待办、草案、完成状态；
- 可视化富文本编辑，支持标题、列表、表格、引用和五色标注；
- 人物、场景、章节使用独立条目记录；
- 故事走向图支持节点、分支、连线、缩放、平移和可调高度分轨；
- 四种界面主题；
- 全文搜索与并发更新检测；
- 网页设置服务端口和访问密码；
- 从另一个 SnowFlake V2.0 SQLite 数据库合并导入作品。

本项目将 `snowflake.db` 纳入版本控制，以便在私有仓库中同步追踪作品设计与代码版本。数据库随 Git 提交同步；复制数据库也可完整迁移全部作品和应用设置。

## 启动

环境要求：Python 3.8+，无需安装第三方包。

```bash
python snowflake.py
```

默认地址为 `http://localhost:10000`，数据库默认为程序目录下的 `snowflake.db`。

```text
python snowflake.py [--db 数据库路径] [-v]
```

- `--db`：指定 SQLite 数据库路径；
- `-v`：显示 HTTP 访问日志。

## 网页使用

- 顶部作品下拉：切换数据库中的作品；
- “＋ 新建”：创建空白作品及完整雪花步骤；
- “导入数据库”：选择 `.db`、`.sqlite` 或 `.sqlite3`，合并其中的作品；
- “⚙”：查看数据库位置、修改服务端口和密码；
- 左侧“故事走向图”：编辑关键节点、分支、分轨和关系。

同名导入作品会自动追加序号。端口修改在重启后生效，密码修改立即生效。
